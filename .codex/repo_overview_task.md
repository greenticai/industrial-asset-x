# Repo Overview Maintenance

Maintain `.codex/repo_overview.md` as a current snapshot of this repository.

The overview must include:

1. High-level purpose.
2. Main components and current functionality.
3. Work in progress, TODOs, stubs, placeholders, and unimplemented areas.
4. Broken, failing, or conflicting areas, including build/test failures.
5. Notes for future work implied by the current repo state.

Refresh the file from current repository contents rather than appending stale information.
